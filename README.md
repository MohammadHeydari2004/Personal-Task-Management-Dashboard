# داشبورد مدیریت وظایف شخصی

یک اپلیکیشن تک‌صفحه‌ای (SPA) پیشرفته و حرفه‌ای برای مدیریت وظایف روزانه که با تمرکز بر **تایپ‌سیفتی کامل**، **دسترس‌پذیری (Accessibility)**، **حالت تاریک/روشن**، **طراحی واکنش‌گرا** و **معماری کامپوننت‌محور مدرن** توسعه داده شده است. این پروژه از آخرین نسخه‌های React 19، TypeScript 6 و Vite 8 بهره می‌برد و با فعال‌سازی React Compiler، بهینه‌سازی‌های خودکار را بدون نیاز به تغییر کد ارائه می‌دهد.

---

## 🎯 ویژگی‌های کلیدی

### مدیریت وظایف (CRUD)

- **ایجاد، مشاهده، ویرایش و حذف:** مدیریت کامل وظایف از طریق مودال‌های تعاملی با فرم‌های اعتبارسنجی‌شده
- **تغییر وضعیت سریع (Inline):** تغییر وضعیت وظایف (برنامه‌ریزی‌شده، در حال انجام، تکمیل‌شده) بدون نیاز به باز کردن مودال
- **صفحهٔ جزئیات وظیفه:** مشاهدهٔ کامل اطلاعات وظیفه با امکان تغییر وضعیت، ویرایش و حذف
- **اعتبارسنجی فرم:** بررسی لحظه‌ای ورودی‌ها با نمایش خطاهای کاربرپسند
- **شناسایی هوشمند عقب‌افتادگی:** تشخیص خودکار وظایف عقب‌افتاده با نشانگر بصری ⚠️

### جست‌وجو و فیلتر پیشرفته

- **جست‌وجوی ترکیبی:** جست‌وجوی هم‌زمان در عنوان و توضیحات
- **فیلتر چندگانه:** فیلتر ترکیبی بر اساس وضعیت و اولویت با قابلیت بازنشانی سریع
- **مرتب‌سازی پویا:** مرتب‌سازی بر اساس تاریخ سررسید یا اولویت در هر دو جهت صعودی و نزولی

### آمار و تحلیل لحظه‌ای

- **داشبورد آماری:** نمایش لحظه‌ای کل وظایف، در حال انجام، تکمیل‌شده و عقب‌افتاده
- **کارت‌های بصری:** نمایش آمار با کدگذاری رنگی و آیکون‌های متنی (📋 ⏳ ✅ ⚠️)
- **محاسبات مشتق‌شده:** آمار به صورت خودکار از داده‌های موجود محاسبه می‌شود

### رابط کاربری و تجربه کاربری

- **طراحی واکنش‌گرا:** بهینه‌سازی کامل برای موبایل، تبلت و دسکتاپ
- **پشتیبانی کامل از RTL:** چیدمان راست‌به‌چپ برای زبان فارسی
- **حالت تاریک/روشن:** تغییر تم با ذخیرهٔ ترجیح کاربر در `localStorage` و تشخیص خودکار ترجیح سیستم
- **کتابخانه کامپوننت‌های قابل استفاده مجدد:** Button، Modal، Input، Select، Badge، TextArea، Field، LiveRegion و غیره
- **حالت‌های خالی:** نمایش پیام‌های مناسب در زمان نبود داده یا نتیجه جست‌وجو

### دسترس‌پذیری (Accessibility)

- **مدیریت فوکوس کامل:** مدیریت خودکار فوکوس در مودال‌ها با قابلیت Trap Focus
- **میانبرهای صفحه‌کلید:** بستن مودال با کلید Escape
- **برچسب‌های ARIA:** استفادهٔ جامع از `aria-label`، `aria-modal`، `aria-labelledby` و `role` attributes
- **لینک پرش به محتوا:** امکان دسترسی سریع کاربران صفحه‌کلید به محتوای اصلی
- **اعلان‌های دسترس‌پذیر:** استفاده از `LiveRegion` برای اطلاع‌رسانی عملیات حذف به صفحه‌خوان‌ها
- **ساختار معناگرا:** استفادهٔ صحیح از تگ‌های `section`، `header`، `main` و سلسله‌مراتب هدینگ‌ها

## 🏗 معماری داده‌ها

### الگوهای طراحی

- **اتحادهای محدود (Literal Unions):** برای `Priority` و `TaskStatus` جهت جلوگیری از حالت‌های نامعتبر
- **اتحاد متمایز (Discriminated Union):** برای مدیریت حالت مودال با `Type Narrowing` خودکار
- **تایپ‌های کمکی (Utility Types):** استفاده از `Omit` برای جداسازی تایپ فرم از مدل دامنه
- **Type Guards:** اعتبارسنجی runtime داده‌ها با `taskGuard`

## 🔧 پیکربندی‌ها

### TypeScript

- **Strict Mode:** فعال برای ایمنی کامل تایپ‌ها
- **Bundler Mode:** بهینه‌سازی برای Vite
- **No Unused Locals/Parameters:** جلوگیری از کد مرده
- **Verbatim Module Syntax:** بهبود عملکرد import/export

### Tailwind CSS v4

- استفاده از `@import "tailwindcss"` در CSS
- پلاگین `@tailwindcss/vite` برای ادغام کامل با Vite
- پشتیبانی از RTL با `dir="rtl"` در HTML
- تعریف `@custom-variant dark` برای حالت تاریک کلاس‌محور

### React Compiler

- فعال‌سازی خودکار بهینه‌سازی‌های کامپایلر با `babel-plugin-react-compiler`
- کاهش re-renders غیرضروری
- بهبود عملکرد بدون تغییر کد
- استفاده از `@rolldown/plugin-babel` برای یکپارچگی با Rolldown

### حالت تاریک/روشن

- مدیریت تم با هوک سفارشی `useTheme`
- ذخیرهٔ ترجیح کاربر در `localStorage`
- تشخیص خودکار ترجیح سیستم با `prefers-color-scheme`
- اعمال کلاس `dark` به عنصر ریشهٔ سند
